# Внесок у проєкт

Дякуємо за інтерес до Freecora CRM Desktop. Нижче — усе, що потрібно знати, щоб запустити проєкт і надіслати зміни.

## Що це за проєкт

Це тонка обгортка Electron навколо вебзастосунку [Freecora CRM](https://freecora.com). Вона **не містить інтерфейсу CRM** — сайдбар, шапка й усі розділи приходять із сайту. Тож зміни в цьому репозиторії стосуються поведінки вікна, меню, збірки й оформлення власних сторінок застосунку (сплеш та екран помилки).

Якщо ви хочете змінити щось у самому інтерфейсі CRM — це репозиторій [`mrnko/freecora`](https://github.com/mrnko/freecora), не цей.

## Середовище

- **Node.js 20+** (версія зафіксована в [`.nvmrc`](.nvmrc)).
- **Windows 10+** для збірки інсталятора. Розробляти й запускати можна на будь-якій платформі, але артефакти проєкт випускає лише для Windows.

```bash
npm install
npm start          # запуск
npm run dev        # запуск із інструментами розробника
```

Щоб працювати проти локального середовища CRM:

```bash
set FREECORA_URL=https://app.freecora.test && npm start
```

## Структура

| Шлях | Призначення |
|---|---|
| `src/main.js` | Головний процес: створення вікна, правила навігації, IPC |
| `src/menu.js` | Нативне меню |
| `src/config.js` | Адреси, білий список хостів, дефолти вікна |
| `src/window-state.js` | Збереження геометрії вікна |
| `src/preload.cjs` | Місток між головним процесом і власними сторінками |
| `src/renderer/` | `loading.html` і `error.html` |
| `scripts/generate-icons.mjs` | Генератор іконок |
| `electron-builder.yml` | Конфігурація збірки |

## Стиль коду

Проєкт свідомо тримається без лінтера й бандлера — тримайте це так само:

- Відступ — **4 пробіли**, лапки одинарні, крапка з комою обовʼязкова (див. [`.editorconfig`](.editorconfig)).
- Головний процес — **ESM** (`import`). Preload — **CommonJS** (`.cjs`), бо режим `sandbox` не підтримує ESM-імпорти.
- Коментарі та рядки інтерфейсу — **українською**, як і в самій CRM.
- Нових залежностей не додаємо без вагомої причини: зараз їх рівно дві, і це перевага.

## Гілки й коміти

- Гілки від `main`: `feat/коротка-назва`, `fix/коротка-назва`, `docs/коротка-назва`.
- Коміти — [Conventional Commits](https://www.conventionalcommits.org/uk/v1.0.0/): `feat: додати пункт меню «На головну»`, `fix: не показувати помилку при ERR_ABORTED`.
- Один коміт — одна зміна. Історію тримаємо читабельною.

## Перед pull request

1. `npm start` — застосунок піднімається, CRM завантажується, вікно відновлює геометрію.
2. Перевірте зовнішнє посилання — воно має відкритися в системному браузері, а не у вікні застосунку.
3. Перевірте сторінку помилки: `set FREECORA_URL=https://app.freecora.invalid && npm start`.
4. `npm run build:dir` — збірка проходить без помилок.
5. Опишіть зміну в [`CHANGELOG.md`](CHANGELOG.md) у розділі «Не випущено».

## Випуск нової версії

1. Підняти `version` у `package.json`.
2. Перенести накопичене з «Не випущено» в новий розділ `CHANGELOG.md` з датою.
3. Створити тег `vX.Y.Z` і надіслати його — GitHub Actions збере інсталятор і портативну версію та прикріпить їх до релізу.
