# Збірка

## Вимоги

- **Node.js 20+** — версія зафіксована в [`.nvmrc`](../.nvmrc).
- **Windows 10+ x64** — інсталятор NSIS збирається лише на Windows.

```bash
npm install
```

> Якщо після `npm install` бракує самого рантайму Electron (npm може не виконати postinstall-скрипт пакета), завантажте його вручну:
>
> ```bash
> node node_modules/electron/install.js
> ```

## Команди

| Команда | Що робить |
|---|---|
| `npm start` | Запускає застосунок із вихідників |
| `npm run dev` | Те саме, але з відкритими інструментами розробника |
| `npm run icons` | Перегенеровує `build/icon.ico` та `build/icon.png` |
| `npm run build:dir` | Збирає розпаковану версію в `dist/win-unpacked` — швидка перевірка без інсталятора |
| `npm run build:win` | Повна збірка: інсталятор + портативна версія |

## Артефакти

Після `npm run build:win` у каталозі `dist/` зʼявляться:

| Файл | Опис |
|---|---|
| `Freecora-CRM-Setup-<версія>.exe` | NSIS-інсталятор: вибір каталогу, ярлики на робочому столі та в меню «Пуск», запис у список встановлених програм |
| `Freecora-CRM-<версія>-portable.exe` | Портативна версія — один самодостатній файл |
| `win-unpacked/` | Розпакований застосунок (проміжний результат) |

Налаштування збірки — в [`electron-builder.yml`](../electron-builder.yml). У пакунок потрапляють лише `src/**`, `package.json` і `LICENSE`; скрипти, документація та знімки екрана лишаються поза ним.

## Іконки

`build/icon.ico` і `build/icon.png` **згенеровані та закомічені**, тож для збірки запускати генератор не обовʼязково.

[`scripts/generate-icons.mjs`](../scripts/generate-icons.mjs) не має зовнішніх залежностей: він малює логотип Freecora процедурно через signed-distance fields у тій самій 48-одиничній системі координат, що й `public/favicon.svg` у репозиторії CRM, рендерить із дворазовим суперсемплінгом, кодує PNG вбудованим `zlib` і пакує кадри 16/24/32/48/64/128/256 у `.ico`.

Версія для `.ico` має заокруглені кути (`rx=12` при боці 48, як у SVG) і прозорий фон — так іконка виглядає на панелі задач. Версія `.png` — full-bleed, без заокруглення, для документації.

Запуск після зміни логотипа:

```bash
npm run icons
```

## Підпис коду

Не налаштований: сертифіката немає. Наслідок — при першому запуску Windows SmartScreen показує «Windows захистив ваш ПК» і вимагає **Детальніше → Виконати в будь-якому разі**.

Щоб додати підпис, знадобиться сертифікат code-signing (OV або EV) і два секрети в налаштуваннях репозиторію — `WIN_CSC_LINK` (сертифікат у base64) та `WIN_CSC_KEY_PASSWORD`. electron-builder підхопить їх автоматично, змінювати конфігурацію не потрібно.

## Збірка в CI

[`.github/workflows/build.yml`](../.github/workflows/build.yml) збирає артефакти на `windows-latest`:

- **вручну** — через **Actions → Build Windows → Run workflow**;
- **автоматично** — при надсиланні тега `v*`; у цьому випадку інсталятор і портативна версія прикріплюються до GitHub Release.

Випуск нової версії:

```bash
# 1. підняти version у package.json і оновити CHANGELOG.md
git commit -am "chore: release v1.0.1"
git tag v1.0.1
git push origin main --tags
```
